# osullivan-2021-unknown

O'Sullivan et al. (UCL/Morton group/Mølmer, 2021) reported the preprint of the random-access quantum memory work subsequently published as O'Sullivan et al. Physical Review X 12, 041014 (2022). This preprint presents the same core content: chirped WURST (Wideband Uniform Rate Smooth Truncation) pulse phase encoding of distinct spectral memory modes using Bi donors implanted in natural Si (~10^17 cm^-3, top 1 µm), coupled to a Nb superconducting resonator (7.093 GHz, Q~18,400) at 100 mK. Different WURST chirp pulses labelled 16 spectrally distinct memory modes. Four weak microwave excitations (~1200 photons each) were stored simultaneously and retrieved in arbitrary order, with storage times ranging from 0.5 to 2.5 ms. WURST dynamical decoupling extended TM=2.0(2) ms (factor of ~3 over Hahn echo T2~0.7 ms). Memory emission efficiency was η_em=0.17 with cooperativity C~0.07. The preprint demonstrated a FIFO protocol with 5 excitations. This represented the first random-access microwave quantum memory, directly relevant to quantum network nodes requiring on-demand retrieval of stored photonic states, and established chirped pulse encoding as a practical multimode memory protocol for spin-ensemble systems.
