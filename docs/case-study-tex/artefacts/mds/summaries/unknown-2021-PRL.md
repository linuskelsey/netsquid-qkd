# unknown-2021-PRL (Gouzien & Sangouard 2021 — PRL 127, 140503)

Élie Gouzien and Nicolas Sangouard, "Factoring 2048-bit RSA Integers in 177 Days with 13,436 Qubits and a Multimode Memory," Physical Review Letters 127, 140503 (2021). The paper analyses a hybrid quantum computer architecture combining a small processor (2D grid of superconducting qubits) with a temporally and spatially multiplexed quantum memory. Logical qubit states are stored in the memory between processing steps, with addresses identified by spatial and temporal indices; when a qubit is needed it is retrieved via microwave field into the processor. Using 3D gauge colour codes (threshold 0.75%, no magic state distillation required) and the same physical assumptions as Gidney & Ekerå 2021 (10^-3 gate error, 1 µs cycle time), RSA-2048 factorisation is shown to require only 13,436 physical qubits in the processor and 177 days runtime — a reduction of more than three orders of magnitude in qubit count compared to the standard 20-million-qubit architecture, at the cost of ~500× longer runtime. The memory requires 28 million spatial modes, 45 temporal modes, and a storage time of ~2 hours (reducible to 1 second with additional error-correction cycles at ~23% runtime overhead). A concrete realisation is proposed using rare-earth-ion-doped solid-state spin ensembles coupled to superconducting microwave resonators via photon-echo protocols. This is the key reference establishing quantum memories as a route to dramatically reduce QPU qubit requirements.
