# alexander-2023-unknown (Alexander 2023 — UCL PhD thesis)

Joseph Alexander, "Developing a Microwave Quantum Memory with Rare-Earth Doped Crystals," PhD thesis, University College London, July 2023. The thesis couples high-Q superconducting resonators to ytterbium-doped YSO (Yb:YSO) and characterises the spin system with the goal of building a functional microwave quantum memory. Decoherence is found to be dominated by instantaneous diffusion and spectral diffusion, with nuclear spins in the YSO host crystal setting the coherence limit. Two strategies are explored to extend T2: high magnetic field with optimal field orientation, and the zero-field clock transition (ZEFOZ) combined with isotopic purification — both achieve (6 ± 2) ms and (6 ± 1) ms respectively. Cooperativity C > 1 is measured for three distinct Yb spin systems, establishing the foundation for lossless memory protocols. New pulse sequences based on adiabatic fast passage (AFP) are developed, enabling echo silencing and the ABBA random-access memory protocol. The thesis concludes with a proposal for an efficient, long-lived microwave quantum memory using FIB-milled Yb:YSO in an "airplane" resonator geometry to maximise g0. This work is the direct predecessor to Hogan 2026, laying the Yb:YSO groundwork on which unit cooperativity was subsequently demonstrated.
