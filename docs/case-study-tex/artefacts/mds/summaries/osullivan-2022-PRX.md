# osullivan-2022-PRX

O'Sullivan, Kennedy et al. (UCL/Morton group and Mølmer), published in Physical Review X 12, 041014 (2022), demonstrated the first random-access microwave quantum memory using chirped pulse phase encoding. Bi donors implanted in natural Si (~10^17 cm^-3, top 1 µm) were coupled to a Nb superconducting resonator (7.093 GHz, Q~18,400) at 100 mK. WURST (Wideband Uniform Rate Smooth Truncation) chirped pulses, each with a distinct frequency sweep profile, served as π-inversion pulses defining 16 spectrally distinct memory modes. Four weak microwave excitations (~1200 photons each) were stored simultaneously and retrieved in arbitrary, user-selected order with storage times from 0.5 to 2.5 ms. WURST dynamical decoupling extended the effective memory time to TM=2.0(2) ms, approximately three times the Hahn echo T2~0.7 ms. Memory emission efficiency was η_em=0.17 and cooperativity C~0.07. A FIFO (first-in-first-out) protocol with 5 excitations was also demonstrated. The work established that arbitrarily ordered multimode storage and retrieval is achievable with a spin ensemble memory without the need to address individual spin packets optically, a key practical capability for quantum network buffer memories where incoming quantum states must be held and released on demand.
