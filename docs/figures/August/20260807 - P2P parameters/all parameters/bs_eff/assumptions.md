# Key Rate vs BS Efficiency

Fixed parameters for this plot:

- **Fibre length**: 20 km
- **Fibre loss**: 0.18 dB/km
- **Detector efficiency**: 0.9
- **Dark count rate**: 50 cps
- **Init loss**: 0.1
- **Node loss**: 2.0 dB
- **Source error rate**: 0.015
- **Dephasing rate**: 3.2e-07 /km
- **Runtimes per point**: 1000
- **Error display**: shade
- **Beam splitter efficiency sweep points**: [1.0, 0.995, 0.99, 0.98, 0.97, 0.95, 0.92, 0.9, 0.87, 0.85, 0.8]

Other assumptions:

- Beam splitter efficiency is the swept axis; config value for it is ignored.
- BB84 is unaffected by beam splitter efficiency and appears as a flat reference line.
