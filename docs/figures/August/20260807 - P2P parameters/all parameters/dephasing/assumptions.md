# Key Rate vs Dephasing Rate

- **Fibre length**: 20 km
- **Fibre loss**: 0.18 dB/km
- **Detector efficiency**: 0.9
- **Dark count rate**: 50 cps
- **Init loss**: 0.1
- **Node loss**: 2.0 dB
- **Source error rate**: 0.015
- **Beam splitter efficiency**: 0.97
- **Runtimes per point**: 1000
- **Error display**: shade
- **Dephasing sweep points (/km)**: [3e-08, 1e-07, 2e-07, 2.6e-07, 3.2e-07, 3.8e-07, 6e-07, 1e-06, 3e-06]

Other assumptions:

- Dephasing rate is the swept axis; config value for it is ignored.
