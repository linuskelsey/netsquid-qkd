# Key Rate vs Dark Count Rate

Fixed parameters for this plot:

- **Fibre length**: 20 km
- **Fibre loss**: 0.18 dB/km
- **Detector efficiency**: 0.9
- **Init loss**: 0.1
- **Node loss**: 2.0 dB
- **Source error rate**: 0.015
- **Dephasing rate**: 3.2e-07 /km
- **Beam splitter efficiency**: 0.97
- **Runtimes per point**: 1000
- **Error display**: shade
- **Dark count sweep points (cps)**: [0, 1, 5, 10, 25, 50, 75, 100, 150, 200, 250]

Other assumptions:

- Dark count rate is the swept axis; config value for it is ignored.
